# 🐧 LinuxKit

### Guía práctica e interactiva de comandos Linux

**LinuxKit** es una herramienta web educativa diseñada para facilitar el aprendizaje, consulta y uso de comandos Linux. Permite explorar comandos, conocer su sintaxis, comprender su funcionamiento y generar comandos personalizados para diferentes necesidades.

El proyecto está orientado principalmente a estudiantes, administradores de sistemas, desarrolladores y personas que están comenzando a trabajar con Linux, servidores y VPS.

---

## 🚀 Características

* 📚 **Guía de comandos Linux**

  * Descripción de cada comando.
  * Sintaxis.
  * Ejemplos prácticos.
  * Explicación de parámetros y opciones.

* 🔎 **Búsqueda de comandos**

  * Encuentra rápidamente comandos según su nombre o función.

* 🛡️ **Seguridad y administración**

  * Comandos relacionados con usuarios, permisos, procesos, archivos y administración del sistema.

* 🖥️ **Servidores y VPS**

  * Comandos útiles para trabajar con servidores Linux.

* ⚡ **Generación de comandos**

  * Creación de comandos personalizados según la necesidad del usuario.

* 🎓 **Enfoque educativo**

  * Diseñado como material de apoyo para aprender Linux mediante ejemplos prácticos.

## 💻 Instalación

### 1. Clonar el repositorio

```bash
git clone https://github.com/jess300605/LinuxKit.git
```

### 2. Entrar al proyecto

```bash
cd LinuxKit
```

### 3. Instalar dependencias

Con npm:

```bash
npm install
```

O utilizando pnpm:

```bash
pnpm install
```

### 4. Ejecutar en modo desarrollo

```bash
npm run dev
```

o:

```bash
pnpm dev
```

### 5. Abrir en el navegador

```text
http://localhost:3000
```

---

## 📦 Generar una versión de producción

Para crear la versión optimizada:

```bash
npm run build
```

Después:

```bash
npm start
```

## 🎯 Objetivo del proyecto

LinuxKit nace como un proyecto educativo para reunir en una sola herramienta diferentes comandos y conocimientos necesarios para trabajar con sistemas Linux.

El objetivo es que el usuario no solamente copie un comando, sino que pueda comprender:

* Qué hace.
* Cómo funciona.
* Cuándo utilizarlo.
* Qué parámetros acepta.
* Qué resultado puede esperar.

---

## ⚠️ Uso responsable

Algunos comandos Linux pueden modificar archivos, permisos, usuarios, procesos o configuraciones del sistema.

Utiliza los comandos con precaución y evita ejecutarlos en sistemas que no administras o para los cuales no tienes autorización.

LinuxKit tiene fines **educativos, administrativos y de aprendizaje**.
